# Nivesh: KYC onboarding concept

A clickable prototype by Vritti Khetan (BeFiSc PM assignment). It's one continuous account-opening journey that shows how KYC can stop leaving users guessing.

**Try this path:** Open my account → Before you start → Fetch PAN from DigiLocker → Is this you? → Bank (pre-check spots a name mismatch) → Fix it now (try हिंदी) → Upload proof → Selfie → Sign → eSign OTP (tap "Didn't get the OTP?") → Application submitted → Status. Wait a few seconds for the notifications.

Turn on **Show new features** (above the phone) to outline every new feature.

## Files

```
index.html   page
styles.css   design and animations
app.js       all screens and text (edit wording in SCREENS)
favicon.svg
```

Plain HTML, CSS and JavaScript, with no build step and no installs.

## Run locally

Double-click `index.html`, or run `python3 -m http.server` in this folder and open http://localhost:8000.

## Put it on GitHub

On github.com, create a new repository, click **"uploading an existing file"**, drag in all the files, and click **Commit changes**.

## Deploy on Vercel

vercel.com → **Add New… → Project** → import the repo → Framework preset **Other** → **Deploy**.
